# Commit Message title: Settings: Dark mode UI revamp with previews

## ✅ What’s New
- Replaced the main switch with dual activation buttons that update per auto/custom/manual schedules and hide when Battery Saver is active.
- Added dark/light preview cards with wallpaper-backed snapshots via `DarkModeView`/`DarkModeAdapter` plus supporting drawables, chips, and layouts.
- Introduced `DisplayImagePreference` to highlight the current theme state and color accents.
- Refreshed dark mode settings screen structure: new preview header, activation layout, twilight location banner layout, berry black toggle repositioned, and customized footer styling.
- Added string/color resources for the new Dot-style dark mode UI and preview assets (light/dark sketches, ripples, backgrounds).

## ⚙️ Use Case
- Provides a richer, glanceable dark mode experience with live previews and clearer activation behavior across auto, custom, and manual schedules while keeping Battery Saver constraints explicit.
