# Cursor AI Desktop Prompt: Implement AOSPMods SystemUI Modifications

## Task: Implement SystemUI modifications for AOSPMods-inspired features in LineageOS

You are implementing advanced status bar and Quick Settings customizations that require deep SystemUI integration. This involves modifying Android's SystemUI package to add the following features:

## Features to Implement

### Status Bar Features:
1. **Status Bar Height Factor** (50-200%)
   - Modify status bar height dynamically
   - Setting key: `status_bar_height_factor`
   - Default: 100 (100% = normal height)
   - Range: 50-200

2. **Notification Icon Limit** (1-10 icons)
   - Limit number of notification icons shown
   - Setting key: `notification_icon_limit`
   - Default: 4
   - Range: 1-10

3. **Combined Signal Icons**
   - Merge mobile and Wi-Fi signal icons
   - Setting key: `combined_signal_icons`
   - Default: false

4. **Hide Roaming State**
   - Hide roaming indicator in status bar
   - Setting key: `hide_roaming_state`
   - Default: false

5. **VoLTE/VoWiFi Icons**
   - Show VoLTE and VoWiFi icons in status bar
   - Setting keys: `volte_icon_enabled`, `vowifi_icon_enabled`
   - Default: false

6. **Hide Privacy Chip**
   - Hide microphone/camera privacy indicators
   - Setting key: `hide_privacy_chip`
   - Default: false

7. **Multi-row System Icons**
   - Allow system icons to wrap to multiple rows
   - Setting key: `system_icons_multi_row`
   - Default: false

8. **Multi-row Notification Icons**
   - Allow notification icons to wrap to multiple rows
   - Setting key: `notification_area_multi_row`
   - Default: false

9. **Network Traffic Indicator**
   - Show network speed in status bar
   - Setting key: `network_on_sb_enabled`
   - Default: false

### Quick Settings Features:
10. **Volume Unmute Percentage** (0-100%)
    - Set volume level when unmuting
    - Setting key: `qs_volume_unmute_percentage`
    - Default: 50
    - Range: 0-100

11. **Leveled Flashlight**
    - Adjust flashlight brightness levels
    - Setting key: `leveled_flashlight_tile`
    - Default: false

12. **Global Flashlight Level**
    - Apply flashlight level system-wide
    - Setting key: `flashlight_level_global`
    - Default: false

13. **QS Label Scaling** (-50 to +50)
    - Adjust QS tile label sizes
    - Setting key: `qs_tile_label_scale`
    - Default: 0
    - Range: -50 to +50

14. **QS Secondary Label Scaling** (-50 to +50)
    - Adjust QS secondary label sizes
    - Setting key: `qs_secondary_label_scale`
    - Default: 0
    - Range: -50 to +50

15. **QS Pull-down Gestures**
    - Enable pull-down gesture on QS panel
    - Setting key: `qs_pulldown_enabled`
    - Default: false

16. **Pull-down Size** (10-50%)
    - Set QS pull-down area size
    - Setting key: `qs_pulldown_percentage`
    - Default: 25
    - Range: 10-50

17. **Pull-down Side** (left/right)
    - Choose pull-down side
    - Setting key: `qs_pulldown_side`
    - Default: left
    - Values: left/right

18. **One-finger Pull-up**
    - Enable one-finger pull-up gesture
    - Setting key: `one_finger_pullup_enabled`
    - Default: false
